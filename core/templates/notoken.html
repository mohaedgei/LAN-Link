Session code missing or wrong

Every LAN-Link session is protected by a 6-character code. The code is shown as Session in the LAN-Link script window running on the server machine.

type the 6-character session code first

Or open the full link directly: http://<ip>:8080/?t=<code>

Example: http://192.168.1.10:8080/?t=a1b2c3
