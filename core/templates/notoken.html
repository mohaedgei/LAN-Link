Session code missing or wrong

Every LAN-Link session is protected by a 6-character code. Start a session on the server machine with python lanlink.py → option 2, then open the full viewer URL it prints — it ends with ?t=<code>.

Example: http://192.168.1.10:8080/?t=a1b2c3
