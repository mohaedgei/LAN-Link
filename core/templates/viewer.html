Install in 3 steps

Download the APK using the button above (if your phone asks, allow Install unknown apps for your browser).
Install and open LAN-Link, then fill the IP, port and session code shown in the terminal — or just scan the QR. The app remembers everything for next time.
Pick a feature (screen share or a camera), allow the permission and the dashboard starts streaming instantly.
How do I connect the phone?

Start the server in the terminal (python lanlink.py → option 2). A QR code appears. Open the LAN-Link app on the phone and scan it, or copy the IP / port / session code into the app fields. From then on the app keeps the values saved — next runs are one tap.

The video says “waiting for your phone”

The server is up but the app is not streaming yet. Open the app and press one of the three feature buttons (screen share needs the media-permission popup approved). Check that both devices are on the same WiFi and that the IP in the app matches the one printed in the terminal.

Remote control does nothing

Remote taps / swipes / keys are injected through Android accessibility. Open phone Settings → Accessibility → LAN-Link and turn the service on, then start screen share again.

Typing text does nothing

Enable the LAN-Link keyboard once: Settings → System → Keyboards → enable it, then switch to it when a text field is focused on the phone. After the first setup it works automatically.

Is my stream visible to the internet?

No. The server binds inside the LAN only and every page, frame and command is gated by the session code in the QR. Nothing is uploaded anywhere. Rotate the code anytime with python lanlink.py start --new-token.

Where does the APK come from?

The green buttons on this page serve the APK file bundled with this project, or the latest GitHub release when no local copy exists. The project and its source live at github.com/mohaedgei/LAN-Link.
