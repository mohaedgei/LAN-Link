Install in 3 steps

Download the APK using the button above (if your phone asks, allow Install unknown apps for your browser).
Install and open LAN-Link — it is a pure QR reader. Point it at the QR on the PC screen (or use Decode QR from a picture for a screenshot) and the connection starts by itself.
Watch it stream here instantly. The QR itself tells the phone which feature opens: screen share, front or back camera.
How do I connect the phone?

Start the server in the terminal (python lanlink.py). A QR code appears containing a simple readable payload like LL1|192.168.1.10|8080|ab12cd|screen — IP, port, session code and the feature to open. Open the LAN-Link app and scan it: the connection starts automatically.

How do I control the phone from this page (like scrcpy)?

Two one-time switches on the phone make control work:
1. Settings → Accessibility → LAN-Link Control → ON — this injects taps, swipes and keys.
2. Settings → System → Keyboards → LAN-Link Text — this types text.
Then restart screen share. A banner on the Live tab tells you whether control is ON or OFF. Once armed: tap the video to tap the phone, drag to swipe, mouse wheel scrolls, and the Remote control tab has Back / Home / Recents / zoom / typing.

The video says “waiting for your phone”

The server is up but the app is not streaming yet. Scan the QR again with the app (screen share shows one system confirmation popup — press Start now). Check that both devices are on the same WiFi.

Remote control does nothing

Remote taps / swipes / keys are injected through Android accessibility. Open phone Settings → Accessibility → LAN-Link and turn the service on, then start screen share again.

Typing text does nothing

Enable the LAN-Link keyboard once: Settings → System → Keyboards → enable it, then switch to it when a text field is focused on the phone. After the first setup it works automatically.

Is my stream visible to the internet?

No. The server binds inside the LAN only and every page, frame and command is gated by the session code in the QR. Nothing is uploaded anywhere. Rotate the code anytime with python lanlink.py start --new-token.
